SMILES postprocessing hotfix — 2026-10-25
Package base: MOFSynth Fast 3.1.1. Standardizer protocol is now
mofid-neutral-parent-v3-azole-carbon-H-20261025.

Adds a restricted missing-C-H repair for isolated neutral conjugated C/N
five-rings with two double bonds and exactly one residual delocalised ring
radical (N or substituted C). Degree-two, valence-three carbon monoradicals
are capped before the existing azolate/neutral-parent/tautomer convention.
Fused, N-substituted, charged, cumulene, saturated and ambiguous unsupported
patterns are not added to this rule. Heavy-atom connectivity is unchanged.

ACUFEK N valence and qmof-008a6ec B valence failures were traced to upstream
MOFid SMILES. No generic N/B charge or bond-order repair was deployed. In
particular, adding B- then applying the legacy Uncharger changes the hydrogen
count; a separate borate charge/parent convention is required.

The same standardizer serves the SA/HOMO fragment identity and RMSD geometry
identity matching. Identity repair never changes existing geometry coordinates
or adds hydrogens to the selected RMSD XYZ. Full xTB/Ehull calculations were
not run for this hotfix. The stopped batch and historical result files remain
unchanged. Recalculation must use fresh work directories to avoid mixing
standardizer protocols or overwriting frozen evidence.
